# Semantic Scaffolding

By Sirui Tao and Steven P. Dow.

Reader companion to a working landscape-review manuscript. Browse the [TL;DR](https://semantic-scaffoldings.github.io/), [paper](https://semantic-scaffoldings.github.io/living-paper.html), [design atlas](https://semantic-scaffoldings.github.io/design-space-atlas.html) and [examples](https://semantic-scaffoldings.github.io/card-gallery.html).

This repository contains the static reader only. Research operations, private review notes, source PDFs and manuscript editing files are not included.

The gallery presents a selected sample. The full card dataset will be available to download when the paper is released.

For GitHub Pages, select **Deploy from a branch**, **main**, **/(root)** in Settings → Pages.
